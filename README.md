# AI-8850 Acceleration Module Driver

This repository is a small backup mirror for Linux driver sources related to the **M5Stack AI-8850 LLM Acceleration M.2 Module (AX8850)**.

## About the module

The AI-8850 is an acceleration module intended to add dedicated AI workload support to compatible Linux-based systems. It is marketed as an M.2 module for local AI and LLM-oriented workloads.

## Why this repository exists

The main purpose of this repository is to keep a **backup source of Linux drivers** for the module because the primary upstream source from M5Stack has had poor availability.

## Main use case

- Preserve access to Linux driver sources for the AI-8850 module
- Provide a stable fallback location when the original M5Stack repository or download source is unavailable
- Make it easier to archive, inspect, and share the driver code needed to work with the module
